# Skeleton for Hybrid Applications

This project serves as a skeleton for building hybrid applications using Vue or other frameworks. It provides a foundation for developing applications that target both Android and web platforms.

## Prerequisites

Node.js version 18 or higher
npm

## Installation Steps
1. Clone this repository to your local machine:
```bash
git clone https://github.com/bobrobert13/skeleton-for-hybrid-applications-vue-or-other
```
2. Navigate to the project directory:
```bash
cd skeleton-for-hybrid-applications
```
3. Install the dependencies using npm:
```bash
npm install
```
## How to Run the Project

1. To run the application in development mode, use the following command:
```bash
npm run dev
```

2. To build the application for production, use the command:
```bash
npm run build
```
